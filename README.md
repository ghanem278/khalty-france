# 👵 خالتي فرنسا — لعبة تحديات القعدات

لعبة موبايل (Offline PWA) بتتلعب على موبايل واحد: عجلة بسهمين ← حجر ورقة مقص ← تحدي ← نقاط ← جايزة.
مكتوبة بـ HTML/CSS/JavaScript عادي **من غير أي مكتبات ولا Build**.

---

## ▶️ إزاي أشغّلها؟

**أسهل طريقة:** دبل كليك على `index.html` — بتشتغل على طول (ما عدا الأوفلاين والتثبيت، دول محتاجين سيرفر).

**على الموبايل / بالتثبيت (PWA):** لازم تترفع على سيرفر HTTPS. أسهل حاجة (مجانًا، بالسحب والإفلات):
1. ادخل على [app.netlify.com/drop](https://app.netlify.com/drop) واسحب فولدر `khalty-france` كله.
2. افتح اللينك على الموبايل ← "Add to Home Screen" (أو "Install app").
3. بعد أول فتح أونلاين، اللعبة بتشتغل **بدون إنترنت**.

بدائل: GitHub Pages، Cloudflare Pages، أو محليًا `npx serve .` أو Live Server في VS Code.

> 🎤 التعرف على الصوت للباسورد بيحتاج **إنترنت + HTTPS** (ده من المتصفح نفسه). لو مش متاح الكتابة شغالة عادي.

## 🗂️ الفولدرات (كل حاجة ليها مكان واحد)

```
index.html            ← نقطة الدخول
manifest.webmanifest  ← إعدادات التثبيت
sw.js                 ← الأوفلاين (غيّر VERSION لما تعدّل ملفات)
css/theme.css         ← 🎨 كل الألوان والخطوط
js/config.js          ← ⚙️ النقاط، المؤقتات، الباسورد، مسارات الصوت، ترتيب الشاشات
data/challenges.js    ← 📝 التحديات
data/escapes.js       ← 🆘 وسائل الهروب ونقاطها
data/avatars.js       ← 🙂 الأفاتارات
data/terms.js         ← 📜 صفحة الشروط
assets/logo.svg       ← 🖼️ اللوجو
audio/                ← 🔊 الأصوات (فيه README بأسماء الملفات)
js/logic/             ← منطق اللعبة (بدون DOM — متختبر)
js/systems/           ← صوت، تأثيرات، اهتزاز، تعرف صوتي، تخزين
js/ui/                ← الشاشات
tests/                ← الاختبارات
```

## ✏️ التعديلات الشائعة

### ➕ إضافة تحدي جديد
افتح `data/challenges.js` وانسخ أي سطر:
```js
{ text: "غني أغنية لأم كلثوم" },
```
ده كفاية! (النقاط 5 والـid بيتعمل لوحده). اختياري: `category`، `points`، `duration: 60` (بيظهر عدّاد)،
`flags: ["physical"]` (تنبيه أمان) / `["external"]` (تحدي بره اللعبة) / `["belt"]` / `["spicy"]`.
اللعبة بتتحمل مئات وآلاف التحديات من غير مشاكل.

### 🔢 تغيير النقاط
- التحدي العادي: `js/config.js` ← `points.challenge`، أو `points:` جوه التحدي نفسه.
- الهروب: `data/escapes.js` ← `points` (الـ٥ جنيه `money`).

### 🔑 تغيير الباسورد
`js/config.js` ← `password.answers` (ممكن أكتر من كلمة). بيتجاهل التشكيل والهمزات وشكل التاء المربوطة.

### 🎨 تغيير الألوان
`css/theme.css` — متغيرات `--primary`, `--accent`, `--bg`... وألوان العجلة `--wheel-1..10`.

### 🖼️ استبدال اللوجو
ابدل `assets/logo.svg` (أو اكتب مسار PNG في `js/ui/screens/splash.js`)، وأعد إنتاج أيقونات
`assets/icons/icon-192.png` و`icon-512.png` و`icon-maskable-512.png`.

### 🔊 إضافة الأصوات
شوف `audio/README.md` — أسماء كل ملف وامتى بيشتغل. الأصوات المولّدة بتفضل شغالة لحد ما تحط ملفاتك.

### 🔄 ترتيب الشاشات
`js/config.js` ← `flow`. مثلًا الباسورد قبل الشروط: `["splash","password","terms","setup"]`.

## 🎮 قواعد اللعبة اللي اتنفّذت

1. **العجلة** بتختار اتنين (سهمين عكس بعض). ترتيب الأسماء بيتغير كل لفة. العجلة بتقف فعليًا على الاتنين المختارين.
2. **حجر ورقة مقص** بتسليم الموبايل (محدش يشوف اختيار التاني)، مع تعادل بيتعاد تلقائي. الخاسر ياخد التحدي، والفايز يفلت.
3. **الدور العادل**: اللي نفّذ تحدي أو خد نقاط هروب مش بيطلع تاني قبل ما الدور يعدّي على الكل. الفايز في RPS لسه متاح.
4. **التحدي**: "تم" ← +٥. "لأ" ← وسائل الهروب:
   | الوسيلة | النقاط |
   |---|---|
   | ادفع ٥ جنيه (بتتضاف للصندوق) | 3 |
   | دقيقة بلانك (بعدّاد) | 4 |
   | سؤال صراحة | 2 |
   | ٥ جلدات بحزام (تتقفل من الإعدادات) | 1 |
   | 🃏 جولدن كارد — بتغيّر التحدي، مرة واحدة، من غير نقاط | 0 |
5. **بعد ٧٠ ثانية** من غير قرار: «انطق والا سأشرحنك» (بتتكرر).
6. **النهاية**: الجايزة بتتوزع على أعلى نقاط. اللي معاه أعلى نقاط ومستخدمش الجولدن كارد بيتحسب بحصتين.
   الحساب بيظهر خطوة بخطوة في شاشة النتائج.
7. الجيم بيتحفظ تلقائي — لو عملت ريفرش أو قفلت الصفحة بيرجع من نفس المكان.

## 🤔 قرارات اتخذتها (اقرأها!)

- **قايمة التحديات**: الملف فيه ٦٠ سطر؛ حطيت **٥٨ تحدي حرفيًا** من غير أي تعديل. اللي اتشال:
  السطر «ومعلش حته صياعه» والسطر «يبقوا موجودين هنا برضو ب5 نقط نكمل» — دول باين إنهم ملاحظات ليك مش تحديات.
  وشيلت علامة `:` الزيادة اللي كانت في بداية بعض السطور. الاختبار `tests/logic.test.js` بيقارن النصوص بالأصل.
  التحديات الأربعة (بلانك، صراحة، ٥ جنيه، حزام) موجودة كتحديات عادية بـ٥ نقاط زي ما قلت.
- **«أكثر من ٥٠٠ تحدي»**: اللعبة جاهزة لأي عدد، لكن اللي وصلني ٥٨ بس. ضيف الباقي بنفس الطريقة.
- **آخر لاعب في الدورة**: كل مباراة بتطلّع خاسر واحد بس، فدايمًا هيفضل لاعب واحد ما كملش. بنجوّزه بـ"ضيف"
  (اللي كمّل بأقل عدد أدوار). لو الضيف خسر بياخد تحدي زيادة **بيتحسب له في الدورة الجاية** (ومتوضح على الشاشة).
- **حصتين للفايز بدون جولدن كارد**: لو فايز واحد بس ياخد الصندوق كله أصلًا؛ الحصتين بتفرق **عند التعادل**
  (مثلًا ٣٠ جنيه: اللي معاه الكارت ٢٠، واللي استخدمها ١٠).
- **زر «تعدّي»** بيتخطى التحدي بدون نقاط ومن غير ما دور اللاعب يتحسب (ممكن يقفله `allowSkipChallenge: false`).
- **الصوت**: موسيقى ومؤثرات بديلة مولّدة لحد ما تحط ملفاتك. مفيش أصوات بشرية مولّدة نهائيًا.

## 📱 تحويلها لتطبيق APK
- **الأسهل:** ارفع الموقع HTTPS وادخل [pwabuilder.com](https://www.pwabuilder.com) ← Package for Android.
- أو **Capacitor**: `npm i @capacitor/core @capacitor/cli @capacitor/android` ← `npx cap init` (webDir = `.`) ← `npx cap add android`.
